# Solid Umbrella Weather Website

Create a beautiful, modern, responsive weather website called Solid Umbrella.

Tagline: "Your weather, under one roof."

DESIGN:

Modern, premium-looking weather dashboard.

Dark navy blue background with sky-blue accents.

Clean typography, rounded cards and subtle gradients.

Minimalist umbrella logo.

Smooth animations and responsive design for mobile and desktop.

Make it look like a professional weather application.

FEATURES:

Homepage with Solid Umbrella branding.

Search bar where users can search for any city.

Current weather showing temperature, location, weather condition and feels-like temperature.

Hourly weather forecast.

7-day weather forecast.

Weather information including humidity, wind speed, UV index and visibility.

Weather icons that change according to conditions.

Celsius and Fahrenheit temperature switching.

Loading indicators and friendly error messages.

TECHNICAL REQUIREMENTS:

Use React, HTML, CSS and JavaScript.

Use the free Open-Meteo weather API for real weather information.

Do not use fake weather data in the finished application.

Make the search functionality actually work.

Ensure all buttons and interactive elements work.

Do not require users to register or log in.

Keep the code organised and easy for a beginner to understand.

IMPORTANT:
Prioritise a polished, functional website over unnecessary complexity. Make the website fully responsive and ensure there are no broken features.
